# AWS IAM User with Amazon S3 Full Access

## Project Description
Created an AWS IAM user with programmatic access and attached the AmazonS3FullAccess policy. Configured AWS CLI using IAM credentials and verified that the user can perform S3 operations while access to other AWS services, such as EC2 and RDS, is denied.

## Technologies Used
- AWS IAM
- Amazon S3
- AWS CLI

## Key Features
- IAM user creation
- S3 full access permissions
- AWS CLI configuration
- Access verification
- Restricted access to other AWS services

## Objective
To understand AWS IAM permissions and implement the principle of least privilege.
